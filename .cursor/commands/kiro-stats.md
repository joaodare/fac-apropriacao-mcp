# Kiro stats (o revisor está valendo a pena?)

Rode:

```bash
scripts/kiro-stats.sh 30
```

Interprete em até 5 linhas:
- Precisão geral e taxa de falso positivo
- Quantos P0 aceitos (bugs graves que passariam sem o revisor)
- Qual modo (review/challenge/task/consult) rende mais
- Uma recomendação concreta: manter, ajustar o prompt/modelo do revisor (diga o quê) ou cortar algum modo

Se houver menos de ~20 achados registrados, diga que a amostra é pequena demais para concluir algo.
